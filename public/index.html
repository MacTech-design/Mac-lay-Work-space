Run & Deploy MAC'LAY

MAC'LAY is free, open-source software (MIT licence). It is one small Node.js server with a built-in database — no accounts to pay for, nothing else to install.

💻 Run it on your computer

The quickest way to try it or develop on it.

1
Install Node.js 22.13 or newer from nodejs.org
2
In the project folder run: npm start
3
Open http://localhost:3000 and create an account
4
Make yourself the owner: node server.js --make-owner you@mail.com
5
Reload — the ⚙ owner button appears bottom-left

🌍 Put it online

Any host that runs Node and keeps a disk works (Railway, Render, Fly.io, or your own VPS).

1
Start command: npm start
2
Attach a persistent volume and set DATA_DIR to it — the database lives there
3
Serve over HTTPS and set PRODUCTION=1 (and TRUST_PROXY=1 behind a proxy)
4
Run --make-owner from the host's shell
5
Back up the data/ folder regularly

🤖 MAC AI (optional)

Chat with Claude inside the workspace. The key stays on the server and is never sent to the browser.

1
Create an API key in the Anthropic console
2
Set ANTHROPIC_API_KEY in .env or your host's settings
3
Optional: AI_DAILY_LIMIT caps messages per user per day
4
Switch it off any time from the owner dashboard

⚡ More languages (optional)

JavaScript, Python and HTML always run in the visitor's browser. C, C++, Java, PHP, Bash and SQL need a code runner.

1
Use a Judge0 service (hosted or self-hosted)
2
Set JUDGE0_URL and JUDGE0_API_KEY (plus JUDGE0_API_HOST for RapidAPI)
3
Signed-in users can then run those languages
